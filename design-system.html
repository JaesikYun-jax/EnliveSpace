Enliven Space 디자인 시스템

인라이븐스페이스(인테리어) 홈페이지의 시각 언어를 한곳에 모은 내부 참고 문서입니다. 모던하고 절제된 모노톤 — 검정(#171717)·흰색·그레이를 기본으로, 따뜻한 베이지(#F2D679)를 상담 유도 한 곳에만 포인트로 씁니다. 한글은 나눔스퀘어, 영문/숫자는 G마켓 산스로 통일합니다.

이 페이지에 대하여

· 사이트 내비게이션 어디에도 링크되어 있지 않습니다.
· <meta robots="noindex,nofollow"> 로 검색 색인을 막아둡니다.
· URL(/design-system.html)을 아는 사람만 봅니다.
· 컴포넌트 데모는 실제 /css/style.css 를 불러와 렌더 → 사이트와 항상 동일.

토큰을 바꾸려면

· 색상·간격·헤더 높이 → css/style.css 의 :root
· 글자 크기 배수 → 같은 파일의 --fs-* 4개 변수
· Tailwind 색상 별칭(ink/paper…) → build-pages.mjs 의 tailwind.config
· 수정 후 npm run build & npm run test

13규칙 · 불변식

아래 규칙은 scripts/test-site.mjs 가 강제합니다(머지 전 npm run test 필수, 225+ 검사).

  • Tailwind CDN 설정은 항상 tailwind.config (오타 tailwindcss.config 금지 — 커스텀 색상 전멸).
  • 헤더 로고는 img logo-dark, 푸터 로고는 img logo-light (텍스트 워드마크 금지).
  • 푸터 SNS 정확히 3개: 카카오톡 채널 · Instagram · 네이버 블로그(‘Blog’ 글자 포함). YouTube 금지.
  • 상담 버튼(data-action="consult")은 항상 Tally URL — href="#" 금지.
  • 메인 외 페이지의 히어로 텍스트 오버레이엔 z-10 필수(그라디언트가 글씨 덮음 방지).
  • 히어로 위 반투명 흰색(text-white/80·90) 금지 — 100% 흰색만.
  • 프로젝트 갤러리는 퍼즐형 masonry(layoutMasonry) — 고정 grid-cols-3 로 되돌리지 말 것.
  • 모든 페이지 <head> 에 파비콘 4종 + manifest + theme-color.
